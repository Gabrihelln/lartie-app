# Degradês

Os três degradês da marca. Use só nestes lugares e sempre com os tokens de cor.

- **gradient-icon:** ícone do app e o bloco do ícone nas telas de acesso e no Início "Decidir depois".
- **gradient-splash:** fundo da splash. Texto e símbolo em `brand-cream`.
- **gradient-onboarding:** topo (470 pt) das telas de boas-vindas, esqueci a senha e onboarding, sempre com os dois anéis brancos decorativos. Texto em `on-surface`.
- O CSS completo de cada um está no guia, em Cores › Degradês.
