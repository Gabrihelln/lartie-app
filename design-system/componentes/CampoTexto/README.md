# CampoTexto

Campo de texto com rótulo sempre visível acima, usado em formulários de onboarding, tarefas, itens e fornecedores.

- Rótulo acima do campo em `ios-footnote` Semibold (iOS) ou `md-body-small` Medium (Android), cor `on-surface`.
- Campo com altura `field-height` (52), raio `radius-md`, fundo `surface`, borda 1.5 em `outline`.
- Foco: borda 2 em `primary`.
- Erro: borda `error` e mensagem abaixo em `error`, dizendo como corrigir ("Informe uma data depois de hoje").
- Texto de ajuda opcional abaixo em `on-surface-variant`.
- Use o teclado certo para cada dado: e-mail, telefone, número, data.
